### 🌱 Around the ecosystem

I'm a [Nuxt Ecosystem Team](https://nuxt.com/team) member and part of the [H3](https://github.com/h3js) and [UnJS](https://github.com/unjs) organizations.

My contributions span component APIs and TypeScript inference in [Nuxt UI](https://github.com/nuxt/ui), validation and server utilities in [H3](https://github.com/h3js/h3), and integrations across Nuxt and UnJS communities.

Alongside code, I contribute through API discussions, reproductions, reviews and coordinating changes across repositories.

### 📦 Libraries I maintain

My main personal projects are:

- **[unjwt](https://github.com/sandros94/unjwt)** — a runtime-agnostic JWT toolkit for signing, encryption and key management, built on Web Crypto API.
- **[unsecure](https://github.com/sandros94/unsecure)** — runtime-agnostic cryptographic utilities covering password hashing, one-time passwords, secure randomness and more.

I also maintain:

- **[uns3](https://github.com/sandros94/uns3)** — a small, runtime-agnostic S3 client with streaming, multipart uploads and presigned URLs.
- **[nuxt-pglite](https://github.com/sandros94/nuxt-pglite)** — embedded Postgres tooling for Nuxt development (with a framework agnostic core), testing, server and browser use.
- **[Nuxt QRCode](https://github.com/sandros94/nuxt-qrcode)** — QR code generation and scanning through Nuxt components and composables.
- **[unauth](https://github.com/sandros94/unauth)** — authentication and authorization utilities built on unjwt and unsecure, still evolving.

### 🧩 Long-term projects

Projects I continue to maintain and develop at a quieter pace:

- **[comark-tiptap](https://github.com/sandros94/comark-tiptap)** — a Comark-aware Tiptap toolkit connecting rich-text editing, structured content and Markdown.
- **[tavolato](https://github.com/sandros94/tavolato)** — a small, runtime-agnostic Parquet reader and writer for JavaScript and TypeScript.
- **[nuxt-surrealdb](https://github.com/sandros94/nuxt-surrealdb)** — SurrealDB integration for Nuxt, with SSR-aware composables, server utilities and embedded engines.

### 🚀 Public projects

Beyond libraries, I also spend time building:

- **[AI Rover](https://github.com/sandros94/ai-rover)** — a community-steered autonomous rover exploring procedurally generated Martian terrain, with shared simulation and interactive 2D/3D views. [Try it](https://rover.s94.dev).
- **[Scafo](https://github.com/sandros94/scafo)** — a self-hosted serverless deployment platform for JavaScript applications, using S3-compatible storage for coordination. [Documentation](https://scafo.dev).

### 💼 Beyond open source

I work mainly through commercial outsourcing, building and maintaining full-stack products. From multilingual publishing platforms to live-event matchmaking applications.

Those projects also provide practical feedback for the libraries and frameworks I contribute to.
